## Day 1: Project setup

**What I did:** Installed Git and Python 3.13, created the GitHub repo, copied it to my PC, and set up the project folders (data, src, eval, docs).

**Why:** I wanted one place for all my code and notes that I can pick up from any computer, and that also shows my progress step by step.

**What I learned:** Git and GitHub keep my work backed up and in sync between machines. Keeping secrets like API keys out of GitHub from the start is much easier than fixing it later.
